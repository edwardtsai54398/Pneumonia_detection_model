# 胸腔X光肺炎辨識：遷移學習模型訓練報告 — 大綱

## 第一章｜緒論與資料集介紹

- 胸腔X光肺炎辨識的臨床背景與研究動機
- 資料集介紹：paultimothymooney/chest-xray-pneumonia，樣本規模、類別分布
- 官方資料切分的限制（驗證集僅16張），帶出重新設計資料切分的必要性

## 第二章｜資料前處理與探索性分析

- 影像尺寸與色彩模式的混雜狀況、標準化策略
- 類別不平衡分析（約1:3），決定處理方式（class weight／augmentation）
- 自訂 stratified 驗證集切分邏輯

## 第三章｜模型架構選擇與訓練策略

- 從資料特性出發討論選擇遷移學習的理由：X光影像雖為醫學灰階影像，但仍保有邊緣、紋理、灰階漸層等與自然影像共通的低階視覺結構，適合借助預訓練特徵
- 骨幹候選的篩選依據（文獻回顧＋運算資源限制），說明為何最終選定主力骨幹
- 訓練策略設計：凍結骨幹 vs 全微調的對照實驗設計與理由

## 第四章｜評估指標與模型選擇策略

- 二元分類下的錯誤代價分析：偽陰性（漏診）相較於偽陽性的臨床代價
- 據此說明為何以 Recall 作為 checkpoint 選擇與 early stopping 的主要依據，Accuracy 僅作參考
- 搭配 F1-score、AUC-ROC 作為輔助評估指標

## 第五章｜實驗結果與分析

- 訓練曲線、混淆矩陣
- 凍結骨幹 vs 全微調的表現對比，用數字呈現特徵遷移的有效程度
- Grad-CAM 分析：正確判斷 vs 錯誤判斷樣本的熱力圖比對，找出模型誤判時實際關注的區域

## 第六章｜結論與反思

- 總結遷移學習在此任務上的有效性與限制
- 反思模型可信度的判斷不能只看準確率，還要驗證「關注對不對地方」
- 收尾句：架構選擇應視任務資料與預訓練來源的視覺特性相似度而定，而非預設單一最佳解
